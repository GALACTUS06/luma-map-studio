# Luma-Map Studio

Align projection zones, mask surfaces, composite dancer silhouettes, and sequence cues for a show.

[Open Luma-Map Studio](https://galactus06.github.io/luma-map-studio/)

## Use the console

The **Facade Study** example opens automatically. Desktop Chrome or Edge supports opening and saving show folders. Use desktop Chrome or Edge for device access.

Select **Open projection**, drag the output window to the projector display, and click the image or press F to enter fullscreen. Keep the operator console open to run the show. Use **Blackout** in the console to blank the output.

The page processes device input and imported media in the browser. Device and local folder access depend on your browser permissions.
